# 工地台账

人员、考勤、工资发放、合同收款。浏览器操作。

仓库：https://github.com/qq987985/gongdi-ledger  
当前版本：**1.2.35**（以根目录 `VERSION.txt` 第一行为准）

镜像：

```text
ghcr.io/qq987985/gongdi-ledger:latest
ghcr.1ms.run/qq987985/gongdi-ledger:latest
```

**个人数据只在 NAS / Windows 的 `data` 目录。**  
软件、镜像、容器、本仓库都可以删或重装，只要 `data` 在就能恢复。永远不要删 `data`。

## 飞牛 NAS

目录固定：`/vol1/1000/docker/attendance/`  
`data` 已经有台账的，解压软件时不要覆盖、不要删除 `data`。

本机构建（推荐）：

```bash
cd /vol1/1000/docker/attendance
chmod +x 一键部署.sh 一键拉取.sh 初始化目录.sh
./一键部署.sh
```

打开 `http://NAS的IP:8501`，左下角应显示 **1.2.35**。

拉 GitHub 镜像（Actions 全绿，并且 Packages 里 `gongdi-ledger` 已设 Public）：

```bash
./一键拉取.sh
```

`./一键拉取.sh` 会优先用 `docker-compose.github.yml`（国内加速），没有才用 `docker-compose.yml`。

国内镜像：`ghcr.1ms.run/qq987985/gongdi-ledger:latest`  
compose 文件对照：

| 文件 | 镜像源 | 说明 |
|---|---|---|
| `docker-compose.yml` | `ghcr.1ms.run/...` | **默认，国内加速** |
| `docker-compose.github.yml` | `ghcr.1ms.run/...` | 和上面相同，老脚本兼容用 |
| `docker-compose.ghcr.yml` | `ghcr.io/...` | GitHub 官方源，国内可能拉不动 |
| `docker-compose.build.yml` | 本机构建 | 网络极差或想自己改代码时用 |

compose **只挂 data**，不要再挂 `VERSION.txt`。国内网络建议直接用 `docker-compose.yml`。已经启动过旧容器的，用 `./一键拉取.sh` 即可，数据不会动。

本机构建镜像名：`gongdi-ledger:1.2.35`，端口 `8501:8080`。

## 合同扫描件

1. 打开「合同管理」
2. 先填 **项目名称**
3. 点表格里的项目名称（或新增合同），页面滚到下方
4. 「保存合同信息」**正下方**有虚线框「合同电子版」，点绿色按钮或拖入 PDF / 照片

保存规则：

- 磁盘文件名是 **项目名称-合同电子版**，例如项目叫「某某住宅」，上传后是 `某某住宅-合同电子版.pdf`
- 存在 `data/photos/合同扫描件/`
- **上传成功立刻算有合同**，不用再点保存。列表里 **有合同 / 无合同** 看有没有这个文件
- 把 PDF 直接拷到这个目录、文件名符合规则，打开软件也会自动认成有合同
- 没有合同：不要单独填原因，写在备注里即可
- 上传前必须先有项目名称，否则会提示先填项目名称
- 点「保存合同信息」会弹出确认窗，列出这次改了哪些项

## 项目进度 / 对账单 / 报量

项目进度：在建、完工、总版图、初审、终审、分包结算、结算完成、**结算已开票**、质保期、退质保金、完成。

- 报量是 **含税**：列表和对账单显示 **含税金额**、**开票金额**

## 常见问题

**打开变成 `{"status":500,"unhandled":true,"message":"HTTPError"}`**  
1.0.0 / 1.0.1 拉镜像或打包不完整会这样。用本机构建 `./一键部署.sh`。若 `data/VERSION.txt` 是文件夹，脚本会删掉这个名字。

**网页一直转圈**  
`docker rm -f attendance-app` 再 `./一键部署.sh`。不要删 data。

**找不到上传合同扫描件的地方**  
点表格里的项目名称，页面滚到下方，「保存合同信息」正下方的虚线框。先填项目名称再上传。保存后文件名是 `项目名称-合同电子版.pdf`。

**国内 pull ghcr.io 失败 EOF / 403**  
改用 `ghcr.1ms.run/qq987985/gongdi-ledger:latest`，并把 Packages 设为 Public。不行就继续本机构建。

**GitHub 网页拖文件没反应**  
一次超过 100 个文件。分两次 Commit，或用 Git 客户端。

**Windows 点更新没反应**  
Releases 里要先有比本机新的 `gongdi-windows.zip`。NAS 没有「点更新」，用脚本重建或拉取。
