工地台账 1.2.22

两种用法：
  Windows解压即用/   双击 启动.bat，浏览器打开 http://127.0.0.1:8501
  Docker-NAS/        解压到飞牛 /vol1/1000/docker/attendance/ ，和已有 data 平级，再 ./一键部署.sh

Windows 的 data 和 NAS 的 data 互不相通，不要混用。
永远不要删 data。

1.2.22：
  版本号后面带发布日期。

1.2.21：
  检测更新走国内加速，超时不再卡住。点检查更新会重新向 GitHub 查询。本机版本读软件自带说明，不被 data 里旧文件带偏。

1.2.20：
  报销单去掉筛选/打印用日期，编辑里不再放大图，列表只留查看/下载/复制/删除。挂账可取消，已报销也可标回未报销。几笔一起打款的凭证改叫「收报销款-金额-几笔」。上传遇到同名文件会问替换还是增加，增加会在后面加 -2。

1.2.19：
  导入导出主按钮改叫导出总台账。可按全部年份、按年或按区间导出，并分项导出人员、考勤、发放、报销、合同。

1.2.18：
  GitHub 有新版本时左下角会提醒。飞牛点更新会自动拉镜像并重启，Windows 仍下载解压包。台账不会动。第一次请先运行一次一键拉取。

1.2.17：

1.2.16：

1.2.15：
  发放记录搜索只查实际收款人和收款人。搜名字不会再把发放方带这个名字的其他人列出来。
