# 查询整月与工资打印精简（2026-11-15）

## 用户决策与实现

1. 开始月份从 1 日开始，结束月份到最后一天。查询页面只选年月，自动与手动都覆盖完整月；反选先交换月份，再取首月1日、末月末日，闰年二月也正确。工资自动范围仍依据当前对象的有内容考勤及相关 owner/receiver 有效已发所在月份，无日期待发不扩大范围。
2. 打印工资不需要整段“工资计算”，表格中提供日工资与折算工资即可。个人查询、班组逐月、工资条统一去掉长公式和计算段；每月金额行下方用一行表格列出当月生效的日/月工资、折算日工资或小时单价、加班折算标准，保持九列金额表可读。
3. 出勤工资、加班工资、补助（含餐补）、罚款/扣款、应发及合计保留。打印补助是原其他补助与餐补合计，表头明确包含餐补；原应发及逐笔舍入时点不变。必要的取分差额仅在备注短注。屏幕原有详细说明保留，用户本次明确简化的是打印。

沿用手动月份跨对象/内容和同册刷新保留、“按数据日期”恢复自动、切册重置。共享的按日起止纯函数保留，查询页面通过 `queryMonthRange` 使用整月范围，不修改其他模块的按日筛选。

## 文件与验证范围

- 日期：`query-data.ts`、`query.tsx`；自动日期规范化到月初/月末，整月函数复用既有规范化与月份枚举。
- 工资：`query-wage.ts` 提供简短标准字段、补助合计及取分短注；`wage-calculation.tsx` 提供表内标准行、备注和完整词表头。
- 打印：`query-month-table.tsx`、`query-sheet.tsx`、工资条与 `print-cols.ts/styles.css`。工资条固定列宽，三入口均不渲染长计算块，空月份无标准空行，考勤件无工资资料。
- 规范：开发规范、AGENTS、使用说明与版本 1.9.6 同步。生产 data 未读写，未做模型迁移。
