| health/auth 失败错误进入本地业务界面 | 未明确本地模式前保守处理；认证异常显示连接失败/重试；只有明确 persist:false 可启用本地模式 |
| 身份确认前启动 seed | 唯一入口等待 hydration、认证、缓存归属后才开放同步；默认暂停，换身份禁止 seed，重试/退出用 epoch 废弃旧队列和迟到版本响应；真实 store 与慢身份浏览器回归验证 |
| XML 显示名伪装 PDF | 响应类型决定预览；XML/HTML/SVG 不进入 iframe，无 MIME PDF 仅下载。附件响应区分 inline/attachment，追加 no-store/nosniff |
| PDF sandbox 兼容性 | 真浏览器发现 sandbox 会屏蔽 Chrome PDF 阅读器，取消该属性；保留明确 PDF MIME 门禁。独立复核确认只有一个 PreviewTarget 构造点且 MIME 与 object URL 来自同一个 Blob |
| 表格拖动与本机存储失败 | 松手/失焦/卸载清理监听与鼠标样式，偏好存储异常不破坏操作；宽表可键盘聚焦 |

| 发版绕过测试 | docker 生效配置与模板增加同一提交的 quality 前置任务，镜像与 Windows job 都依赖成功；本地守卫含坏样本自检 |
| 考勤月表合计金额挤列 | 真 PDF 发现合计越界；金额列扩大、减少横向留白、等宽数字右对齐，保留字号和千位符；12 人长备注样本仍为一页，101,760.00 合计清楚完整 |
| 审计修改/删除与追加并发 | 追加、修改、删除共用读改写队列；局部读取结果及坏文件状态按册隔离，删除先留痕且保留该条。5 条真实回归覆盖混合并发、坏文件、跨册上下文及失败恢复；修复前两条并发用例失败，修复后通过。事务提供串行化，不承诺多次落盘自动回滚 |

## 3. 性能实测

本机 Node v24.20.0，同一合成数据：1,000 人、36,000 条考勤、12,000 条发放，5 次运行取中位数。

| summarizeYear | 修改前 | 修改后 |
|---|---:|---:|
| 中位耗时 | 727.31 ms | 12.03 ms |

约 60 倍是**该函数与该数据规模**的结果，不代表全应用速度；优化前后完整返回结果深比较一致。脚本 `ci/summary-benchmark.mjs` 支持 `--save` / `--compare`。本次基线和结果日志在临时目录，不作为产品数据入库。

## 4. 协作及复核

本轮实际调用 3 位专家：Software Architect（规范、发布门禁、局部打印修正及审计并发修复）、Application Security Engineer（安全审查和启动模式修复）、Code Reviewer（独立代码复核）；主负责人负责整体实现、规范整合、性能、浏览器与 PDF 验证。

角色读取自本地专家目录。长期规范列出的 9 类专家不代表本次全部调用。安全专家转为实现者后，其启动补丁由未参与实现的 Code Reviewer 复核。复审实际发现了启动 seed 竞态，未以已有测试全绿直接关闭。

## 5. 验证方式与限制

使用 `pnpm run check`（类型、Node 测试、Excel 往返、构建）和构建指纹检查。浏览器使用本机 Chrome、隔离测试服务和合成台账。

- 14 个桌面页面；14 页 × 375×667/390×844 手机视口；5 类编辑弹窗 × 两个手机视口。
- 手机初检有 7 个首屏底栏遮挡观察，后续对相关 5 页在两种尺寸进行滚动后的实际命中检查，未发现永久挡住的入口。不能把初检说成零观察。
- 图片预览验证 Tab、Shift+Tab、Esc、焦点恢复；PDF 另查真实渲染，不能用图片用例代替 PDF 内部按键验证。
- 12 种打印输出使用真 PDF；视觉检查发现月表合计挤列并修复，不仅依赖 DOM/自动守卫。
- 新脚本：`ci/optimization-browser-check.mjs`、`ci/nas-mode-browser-check.mjs`；环境变量可指定 Playwright 和 Chrome。

未验证真实 NAS 容器更新、Windows 启动器运行、远程 GitHub Actions、实体打印机、所有浏览器/读屏器。没有推送、部署或发版，不把本地通过写成线上通过。PDF 阅读器内部 Esc/Tab 由浏览器接管，父页面按键监听不能保证覆盖；保留可见关闭与下载入口。

当前整本快照存储、合同财务预设读取权限、root/docker.sock、其余安全专项及姓名照片匹配等事项仍在[唯一待办清单](../README.md#三当前未闭环项唯一清单)，本轮未擅自改变产品决策和生产磁盘格式。
