# 班组考勤与查询核对 · 2026-11-13

基线：`318b7eb`（1.9.0）。交付版本：1.9.1。只使用临时合成台账，未读取或修改生产 `data/`。

## 需求与使用

- 月度考勤：打开月份 → 选择「打印班组」 →「按班组打印考勤」。可选一个或全部班组，仅列姓名、出勤天数、加班小时、班组合计；全部班组自然排版，长表续页重复抬头，合计仅在末尾一次。
- 查询：原「个人查询」更名「查询」。先选按个人/按班组，再选考勤/工资及时间范围 →「打印查询结果」。默认个人考勤，适合与班组或工友核对；工资模式另外保留原工资条入口。
- 考勤查询及其打印件不带工资金额、身份证、银行卡或人员照片。工资核对清单也不打印个人证件与银行卡。

## 计算与范围

- 查询班组来自当前人员档案；月度打印班组来自当前月表（行班组优先，空值回落人员档案），均使用 buckets 并保留未分班组。
- 考勤按完整月份统计；工资发放按规范化起止日期闭区间统计。反向区间年月日一起对调，跨年与真实月末正常处理。
- 查询在 `query-data.ts` 统一计算，屏幕、核对单和工资条复用结果。同月多行逐行调用 `monthPay` 后累加，保持年度 `personMonths` 既有口径，不擅自去重或改变月薪多行含义。
- 工资查询按 owner 统计已发（含代发）；差额为应发减此已发。工资条本人收款仍使用 `isPaidSelf`，代收他人与他人代领分列，待发不混入已发。
- 班组成员含零考勤人员。历史同名人员不猜测关联、不重复计入合计，保留人员行并提示人工核对。
- 工资条勾选受当前班组约束；切范围清空勾选。核对单和工资条打印件互斥，打印在 React 提交对应内容后触发。

## 实现与独立复核

主负责人负责月表班组打印、同步身份、样式、CI 和集成；`/root/query_feature` 独占查询相关实现；`/root/spec_review` 只读独立复核，无生产访问或文件写入。

独立复核发现并关闭两处同源问题：

1. 同册刷新人员班组/工资时，打印发布 effect 只依赖行与 dirty，可能保持旧班组或金额；现同时依赖人员资料和年月。
2. 拉取期间编辑、拉取失败后恢复原身份时，打印可能持续禁用；现显式传入身份并作为发布依赖。同册拉取不重挂载编辑器，不丢未保存修改；切册以身份代际重新绑定。

复核者最终结论：当前审查范围无未解决阻断，相关 25 项测试通过；浏览器及真实 PDF 证据由主负责人统一验证。

后续真实场景另关闭：查询屏幕宽表改为自身区域滑动，固定打印列宽并保持金额完整；打印态清除外壳底部导航预留，日期并入班组表头，末组不留尾部间距，消除 60 人长表的空白第三页。只读工资查询发现身份证隐藏输入、银行/IC 拖放仍可进入上传处理，已在 `photo-slot` 输入、拖放与处理函数三层补齐只读判断，保留查看/复制/下载。这些补丁均经过同一复核者只读复查。
