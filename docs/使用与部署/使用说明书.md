# 工地台账 · 使用说明书

> 面向**使用的人**（工地负责人、资料员、财务），不需要任何技术背景。
> 版本以仓库根目录 `VERSION.txt` 第一行为准（软件左下角也能看到当前版本）。
> 遇到具体报错请直接翻下一份《常见问题解答(FAQ).md》；本文只讲「怎么用」。

---

## 1. 这个软件是什么

一个装在**自己的电脑或 NAS 上**的小系统，把工地上的这些事记在一起：

| 你要记的事 | 在哪个菜单 |
|---|---|
| 工人名单、身份证、工资标准 | **人员** |
| 每天/每月出了多少工 | **月度考勤** |
| 谁拿了多少钱、什么时候打的 | **发放记录** |
| 买了什么、报销了没有 | **报销单** |
| 项目合同、报量、开票、收款 | **合同管理** |
| 团体意外险保单与在保人员 | **团体保险** |
| 身份证照片、合同扫描件等 | **照片** / **影像资料** |
| 某个人一共干了多少、该发多少 | **个人查询** |
| 谁在什么时候改了什么 | **操作记录** |
| 和 Excel 互导、备份 | **导入** / **导出** |
| 账号、权限、界面风格、软件更新 | **设置** |

三句话记住它：

1. **数据只在你自己机器上的 `data` 目录里**（不在云端、不联网上传）。
2. **程序坏了、删了、重装了都不要紧 —— 只要 `data` 还在，数据就都在。**
3. **`data` 永远不要删，也不要上传到网上。**

## 2. 第一次安装

### 2.1 Windows 电脑（最简单）

1. 到 GitHub 的 Releases 里下载 `gongdi-windows.zip`。
2. 解压到一个**不会被误删的目录**（例如 `D:\工地台账\`），不要在压缩包里直接双击运行。
3. 双击 `启动.bat`，浏览器会自动打开 `http://127.0.0.1:8501`。
4. 数据在解压目录下的 `data` 文件夹里。**换电脑时把这个目录整个拷走就是全部数据。**

### 2.2 飞牛 NAS（多人共用一个台账）

把压缩包解压到飞牛的 `/vol1/1000/docker/attendance/`，**和已有的 `data` 目录平级**，然后：

```sh
cd /vol1/1000/docker/attendance
chmod +x 一键部署.sh 一键拉取.sh 初始化目录.sh
./一键部署.sh          # 本机构建（推荐，网络差也能用）
```

打开 `http://NAS的IP:8501`。想用镜像方式则跑 `./一键拉取.sh`（细节见《部署说明.txt》）。

> ⚠️ 解压新版本时**不要覆盖、不要删除 `data`**。升级只换程序，数据永远不动。

## 3. 第一次打开要做的三件事

1. **建管理员账号**：第一个注册的账号就是管理员，密码至少 8 位。这个账号能建别人、能改数据、能更新软件 —— 请记牢。
2. **确认年份 / 台账**：左上角能看到当前年份与台账名。新工地建议新建一本台账，不要和别人的混在一起。
3. **把人员录进去**：到「人员」点**新增人员**一个个加；人多就用「导入」——
   先在导入页**下载模板**，照着模板填好再传上来（模板里的列名不要改）。

---

## 4. 日常怎么录入

- **人员**：`人员 → 新增人员`。身份证号填 18 位（末尾可能是 X），生日、性别会自动算出来。
  工资标准、餐补、加班规则也在同一个弹窗里设；调薪用里面的「工资变更历史」，写清哪天起生效，**过去月份的工资不会被追溯改掉**。
- **考勤**：`月度考勤 → 选月份 → 逐人填工天`/补助/扣款/备注。改完一定要点**保存**；
  没保存就切月份，软件会先问你一句（别点「放弃」）。
- **发放**：`发放记录 → 新增发放`，选人、填金额和打款日期、上传打款凭证。打款凭证建议传，方便以后对账。
- **报销**：`报销单 → 新增报销`，填项目明细与金额。转账/微信支付要传凭证，现金可以不传。
  **几笔一起打款**：勾选多笔 → 一起报销/记打款，凭证只需要传一张。
- **合同**：`合同管理 → 新增合同`。填好项目名称后，在下方虚线框里上传**合同电子版**（PDF 或照片）——
  有文件就算「有合同」，没传就是「无合同」，原因写在备注里。报量、开票、收款在编辑弹窗里逐笔记录。
- **保险**：`团体保险 → 新增保单`，再往保单里**新增人员**。替换人员、在保天数软件会自动算。
- **照片 / 影像资料**：身份证正反面、银行卡、IC 卡、合同扫描件、报量单、发票、回单等，
  都可以直接在对应页面里上传。文件名不用你操心，软件会按「姓名-证件类型」规范命名。

> 提示：**手机也能用**。浏览器输入同一个网址即可，表格可以左右滑动。

## 5. 怎么查、怎么打印

- **查一个人**：`个人查询` → 输入/选择姓名 → 显示他的考勤、工资和打款记录，可直接**打印工资条**。
- **发放清单（按实际收款人）**：`发放记录` 页，先用上面的区间/发放方/状态筛好，统计文字旁边可选
  「全部实际收款人」或某一个人，然后点**打印明细**（每人一节，逐笔列出，带该人小计）或
  **打印汇总**（每人一行，带笔数与合计，表尾总计）。口径与屏幕一致：只算**填了发放日期**的记录，
  待发放不算已发；当前筛选没有已发记录时按钮是灰的，不会打出空白页。
- **对账单 / 报量**：在「合同管理」里点对应合同的打印按钮。
- **导成 Excel**：`导出` → 先选范围（全部年份 / 按年 / 按区间）→ 再点要导的那一项。
  可以整本导出，也可以只导人员、考勤、发放、报销或合同。

## 6. 怎么备份（重要，建议每月一次）

三种方式，任选，**第一种最省事**：

1. **软件内备份**：`设置 → 数据 → 立即备份 Excel`，文件落在 `data/backups/` 里。
2. **导出整本**：`导出 → 全部年份 → 总台账`，得到一个 Excel 文件，存到 U 盘或网盘。
3. **直接拷 `data` 目录**（最彻底、最推荐）：把整个 `data` 文件夹复制一份到别的地方
   （移动硬盘、另一台电脑、NAS 的另一块盘）。**这就是全部数据**：账号、台账、照片、合同扫描件、备份、日志都在里面。

> 恢复数据：把备份的 `data` 目录放回原位（覆盖现在的 `data`），重启软件即可。
> 只恢复某一部分也可以：`data/backups/` 里是历次备份，`data/books/` 是台账数字，`data/photos/` 是影像。

## 7. 怎么升级

**升级只换程序，`data` 一动不动。**

- **软件内一键更新（推荐）**：`设置 → 软件更新 → 检查更新 → 更新`。
  飞牛需要 compose 里挂了 `/var/run/docker.sock`（默认已挂）；Windows 解压版直接点更新。
- **飞牛脚本**：`./一键拉取.sh`（拉最新镜像重建容器）或覆盖文件后 `./一键部署.sh`。
- **Windows**：解压新包，把新包里的程序文件覆盖过去，**保留原来的 `data`**。

升级前建议先做一次第 6 节的备份。升级后左下角版本号应变成新版本；
如果点完更新版本没变，看《常见问题解答(FAQ).md》第 1 条。

## 8. 多个人一起用

- **一个人一个账号**：管理员在 `设置 → 账号` 里建号，按模块授权（人员 / 考勤 / 发放 / 合同 / 报销 / 保险 / 照片 / 查询 / 设置）。
- **只读的给「查询」权限就够了**，不要图省事给管理员。
- **不要两台设备同时改同一本台账**：保存时按服务器版本校验，后保存的一台会收到提示，
  可以选择「用本机覆盖」或「放弃本机」，不会被悄悄覆盖 —— 但**同时改仍有覆盖风险**，
  建议固定一台设备录入、其他设备只看。
- **换了谁操作都有记录**：`操作记录` 里能看到谁在什么时候改了什么（删除和修改只有管理员能操作）。

---

## 9. 出问题了先看哪里

1. **界面上有红字提示**：按提示操作（多数是权限不够、文件太大、格式不对，提示里会写原因）。
2. **`data/logs/` 目录**：按日期命名的日志文件，出错原因写在这里。
   日志只保留最近 14 天、单文件最多 8MB，不会把磁盘占满，不需要你手动清理。
3. **升级相关问题**：`设置 → 软件更新 → 查看更新日志`，能看到最近一次更新做了什么。
4. **还是不行**：不要删 `data`、不要手工改 `app/` 里的文件，把现象和日志截图发给维护的人。

---

## 10. 三条红线

1. **永远不要删 `data` 目录**（删了就等于把工地的账全删了）。
2. **不要把 `data` 上传到 GitHub 或任何网盘公开链接**（里面是身份证、银行卡、合同）。
3. **不要手工改 `app/` 里的文件**（那是程序文件，升级会被覆盖；要改程序改 `src/` 并重新构建）。
