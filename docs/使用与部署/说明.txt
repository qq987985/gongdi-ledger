工地台账 · 三分钟上手
（版本号以仓库根目录 VERSION.txt 第一行为准；完整功能说明见 使用说明.md）

两种用法：
  Windows 解压即用/   双击 启动.bat，浏览器打开 http://127.0.0.1:8501
  Docker-NAS/         解压到飞牛 /vol1/1000/docker/attendance/ ，和已有 data 平级，再 ./一键部署.sh

第一次打开：
  1. 设置管理员账号和密码（至少 8 位）。
  2. 在「人员」里建档，在「月度考勤」里录工天，在「发放记录」里记打款。
  3. 「个人查询」可打印工资条；「导出」可备份整本台账为 Excel。

更新：
  设置 → 软件更新 → 检查更新 / 更新（飞牛需已挂 docker.sock，Windows 解压版直接点更新）。
  也可以照旧 ./一键拉取.sh（飞牛）或覆盖 app/ 后重启。

切记：
  · 数据全在 data 目录（账号、台账、照片、合同影像、备份、日志）。永远不要删 data。
  · Windows 的 data 和 NAS 的 data 互不相通，不要混用。
  · 多设备请勿同时编辑同一本台账（同时改动会互相覆盖）。
  · 历史版本记录见 VERSION.txt，不再在这份说明里重复维护。
