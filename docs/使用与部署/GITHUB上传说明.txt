================================================

网页一次最多 100 个文件，本包超过 100 个。请用 GitHub Desktop，
或先传 app/ 并 Commit，再传其余文件。

.github 文件夹解压后经常看不见。请打开仓库 → Actions → 新建工作流，
把 仓库内的 .github/workflows/docker.yml 全文粘贴保存为 .github/workflows/docker.yml

不要上传：
  data/                 真实台账、账号、照片、合同影像、日志
  node/                 Windows 自带的 node.exe
  node_modules/  dist/  本机依赖与中间产物
  任何 zip 安装包
  办公室原来的人员表、考勤表、合同表（真实名单）
  data/templates/       运行时目录；空白模板由软件内「下载模板」实时生成，仓库里没有静态模板

要上传：
  src/  tests/  scripts/  app/  win/  ci/  docs/  public/
  package.json  pnpm-lock.yaml  tsconfig.json  vite.config.ts
  Dockerfile、docker-compose*.yml、.dockerignore、.gitignore、.gitattributes
  一键部署.sh  一键拉取.sh  初始化目录.sh
  README.md  VERSION.txt  开发规范.md  AGENTS.md
  （app/ 是构建产物，随源码一起上传，部署时无需再装依赖构建）

推到 main 后看 Actions 是否全绿。
然后 GitHub → Packages → gongdi-ledger → 改成 Public。

飞牛上：
  本机构建   ./一键部署.sh
  拉镜像     ./一键拉取.sh
  之后也可以在软件里 设置 → 软件更新 一键更新
