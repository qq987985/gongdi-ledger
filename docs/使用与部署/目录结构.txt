工地台账 · 目录结构
（版本号以 VERSION.txt 第一行为准；本文按 1.8.0 的现状核对）

数据只在 data。空目录由 一键部署.sh / 初始化目录.sh / 启动.bat / 容器启动时 自动创建，
缺哪个补哪个即可，不要删已有文件。


一、data 里都是什么（软件会自动建，不用手建）
--------------------------------

data/accounts/            登录账号、密码（scrypt 加盐）、台账名单、成员权限（accounts.json）
data/books/<台账id>/      这一本台账的数字数据：ledger.json（人员/考勤/发放/合同/报销/保险）、
                          audit.json（操作记录）、book.json（台账名与创建人）
data/backups/             Excel 备份（含最新「考勤表.xlsx」）
data/templates/           导入模板（运行时生成，不要传 GitHub）
data/logs/                服务端日志：YYYY-MM-DD.log（按天）、update.log（一键更新现场）
data/photos/              全部影像。1.7.3 起按台账隔离：
                            photos/<台账id>/id          身份证正反面（张三-身份证-正面.jpg / -反面.jpg）
                            photos/<台账id>/bank        银行卡
                            photos/<台账id>/ic          IC卡
                            photos/<台账id>/报量单  发票  收款回单  考勤影像
                            photos/<台账id>/合同扫描件  （有文件=有合同）
                            photos/<台账id>/报销凭证  报销打款
                            photos/<台账id>/保险合同
                          历史遗留的全局目录 photos/id、photos/合同扫描件 等保留为「只读回落」，
                          老文件不会丢；在 设置 → 影像归入本台账 可一次性复制进本台账。

不要创建 data/VERSION.txt（旧挂载残留会变成文件夹，导致首页 500）。
不要删 books 和 accounts。


二、飞牛 NAS 部署后
--------------------------------

/vol1/1000/docker/attendance/
  data/                         ← 已有台账，不要删、不要覆盖
  app/                          ← 程序（构建产物）
  Dockerfile
  docker-compose.yml            ← 国内加速拉镜像（默认）
  docker-compose.ghcr.yml       ← GitHub 官方源拉镜像
  docker-compose.build.yml      ← 本机构建
  一键部署.sh
  一键拉取.sh
  初始化目录.sh
  VERSION.txt
  .dockerignore
  docs/                         ← 说明文档（使用说明.md 在 docs/使用与部署/）


三、Windows 解压后
--------------------------------

工地台账\
  启动.bat
  停止.bat
  VERSION.txt
  说明.txt
  使用说明.md
  app\
  node\node.exe
  data\                         ← 第一次点启动后自动出现，结构和第一节相同


四、GitHub 仓库（不要上传 data、node、node_modules、dist、zip）
--------------------------------

  README.md  VERSION.txt  开发规范.md  AGENTS.md     ← 四个入口文档
  docs/                    ← 全部说明与审查报告（使用与部署 / 审查与报告）
  src/                     ← 完整 TypeScript 源码（页面、组件、库）
  tests/                   ← 零依赖回归测试（node 内置测试器）
  scripts/                 ← 生产启动器与产物整理脚本
  ci/                      ← 质量闸门与发版说明（workflow 需在 GitHub 网页启用）
  app/                     ← 构建产物（pnpm build 生成，不要手改）
  win/                     ← Windows 启动/停止/打包脚本
  public/  package.json  pnpm-lock.yaml  tsconfig.json  vite.config.ts
  Dockerfile  docker-compose*.yml  .dockerignore  .gitignore
  一键部署.sh  一键拉取.sh  初始化目录.sh

空白导入模板由软件内「下载模板」按钮实时生成，仓库里没有静态 xlsx 模板。
