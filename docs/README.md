**A. 需要专门排期的**

1. **实体级存储**：整本台账仍是一个 `ledger.json`，每次改动整本上传（实测「中等工地」约 1.45 MB/次）。
   要拆成按实体保存 + 索引，属专项改造，别在改功能时夹带。方案见 `架构审核报告-20260910.md` §2「中期」。

   > （整本 PUT 是客户端同步机制，能改考勤数据的人必须能保存；收严会出现「能改考勤却保存不了」，
   > 要收严须先做按模块增量写 = 就是本条专项）。**不再作为待修缺陷**，决策记录见
   > `功能测试-A-账户权限设置-20260916.md` 文末「处理状态（1.8.9）②」+ `AGENTS.md`「已决策」。
