工地台账 1.2.0  目录结构
================================

数据只在 data。下面这些空目录都可以自动创建：
  一键部署.sh / 初始化目录.sh / 启动.bat / 容器启动时
缺哪个补哪个即可，不要删已有文件。


一、必须创建的 data 目录（14 个）
--------------------------------

data
data/accounts
data/books
data/backups
data/templates
data/photos
data/photos/id
data/photos/bank
data/photos/ic
data/photos/报量单
data/photos/发票
data/photos/收款回单
data/photos/考勤影像
data/photos/合同扫描件
data/photos/报销凭证
data/photos/报销打款

books 下面的「台账编号」文件夹不用手建，软件新建台账时会建。
不要创建 data/VERSION.txt（旧挂载残留会变成文件夹，导致首页 500）。


二、data 里都是什么
--------------------------------

data/accounts/          登录账号、密码、台账名单、权限
data/books/编号/        这一本台账的人员、考勤、发放、合同、操作记录
data/photos/id/         身份证正反面   张三-身份证-正面.jpg / 张三-身份证-反面.jpg
data/photos/bank/       银行卡照片     张三-银行卡.png
data/photos/ic/         IC卡照片       张三-IC卡.jpg
data/photos/报量单/     合同报量影像
data/photos/发票/       发票影像
data/photos/收款回单/   收款回单
data/photos/考勤影像/   月度考勤影像
data/photos/合同扫描件/ 合同原件扫描（文件名=项目名称-合同电子版，如 某某住宅-合同电子版.pdf；有文件=有合同）
data/photos/报销凭证/ 报销影像（文件名=项目名称-金额，几笔可共用一张；现金可不传）
data/photos/报销打款/ 打款回单（几笔一起报销共用一张；文件名=报销人-账户-合计）
data/backups/           Excel 备份
data/templates/         导入用模板（运行时目录，不要传 GitHub）


三、飞牛 NAS 部署后
--------------------------------

/vol1/1000/docker/attendance/
  data/                         ← 已有台账，不要删、不要覆盖
  app/                          ← 程序
  Dockerfile
  docker-compose.yml            ← 拉 GitHub 镜像
  docker-compose.build.yml      ← 本机构建（推荐）
  docker-compose.github.yml     ← 国内拉镜像
  一键部署.sh
  一键拉取.sh
  初始化目录.sh
  VERSION.txt
  .dockerignore
  部署说明.txt
  使用说明.md
  目录结构.txt


四、Windows 解压后
--------------------------------

工地台账\
  启动.bat
  停止.bat
  VERSION.txt
  说明.txt
  app\
  node\node.exe
  data\                         ← 第一次点启动后自动出现，结构和上面相同

Dockerfile

docker-compose.build.yml        ← 本机构建
.dockerignore
.gitignore
VERSION.txt
README.md
使用说明.md
目录结构.txt
部署说明.txt

一键拉取.sh
初始化目录.sh
win/启动.bat
win/停止.bat
win/pack.sh
app/                            ← 含 app/public/templates 空白导入模板，要上传
