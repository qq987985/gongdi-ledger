# Excel 往返用例（70 个）

这是一次全量走查时写的独立往返套件（1.7.13 引入仓库）：把导出的工作簿再导入回来，
逐字段/逐条数核对，覆盖 人员 / 考勤 / 发放 / 合同 / 报销 / 保险 / 整本 / 边界 八组。

跑法（不依赖 vitest，直接用 Node 跑 TS 源码）：

```sh
pnpm run test:roundtrip
```

它和 `pnpm test`（Node 内置测试器跑 `tests/*.test.ts`）互补：
`pnpm test` 里是源码级断言，这里是"导出→导入"整条链路的对拍。
历史上这一块出过「报量被换成含税金额」「开票翻倍」「跨年考勤落到第一年」「调薪历史被清空」等问题，
所以改动 Excel 相关代码时**两个都要跑**。
