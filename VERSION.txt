1.3.3

[1.3.3] 2026-09-03
修复 Windows 启动.bat 服务启动问题，简化脚本直接运行 node。
- 人员编辑器新增「工资变更历史」区域，可添加多条工资记录。
- 考勤计算自动根据年月匹配对应的工资记录，变更日前后工资自动切换。

人员餐补功能：支持按正常出勤天数计算餐补，加班折算的工天不算。
- 人员表新增「餐补/天」字段，在人员编辑器工资区域设置。
- 工资历史记录也支持餐补，变更日期后自动切换。
- 考勤月表新增「餐补」列，汇总显示总餐补。
- Excel 导出考勤表包含餐补列。

导入功能增强：人员、考勤、发放、报销、合同五个模块支持「增加/替换」模式。

Windows 版本修复：
- 启动.bat 等待服务就绪后再打开浏览器。
- 首次运行自动创建 data 目录结构。
- 绑定 127.0.0.1 避免防火墙拦截。
- 支持文件夹任意改名/移动。

修复软件内「检查更新/更新」时空请求体导致 invalid JSON 报错，升级 POST 请求改为发送空 JSON body。

[1.2.24] 2026-09-02

整理出可读源码目录 src/，按页面和模块分开，便于备份和交给别人改。飞牛仍运行 app/，台账 data 不动。
