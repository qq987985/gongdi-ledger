完整包 1.0.1

一、传到 GitHub（网页一次最多 100 个文件）
1. 仓库文件删光后，先拖 app 文件夹，Commit
2. 再拖其余文件（Dockerfile、win、VERSION.txt、README.md、docker-compose.yml 等）
3. .github 是隐藏文件夹。网页新建文件，名字填：
   .github/workflows/docker.yml
   内容用本包里的 docker-workflow.yml 整份粘贴
4. 等 Actions 里 image 变绿

二、NAS
data 不要删。compose 用本包 docker-compose.yml：
  image: ghcr.1ms.run/qq987985/gongdi-ledger:latest
然后：
  cd /vol1/1000/docker/attendance
  docker compose pull
  docker compose up -d

拉不到镜像时，把本包 app、Dockerfile 拷到 NAS 目录，执行 ./一键部署.sh

三、不要把 VERSION.txt 单独挂进容器，只挂 data 目录。
